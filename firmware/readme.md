## 🔬 Profiling and Hardware Abstraction (HAL)

When compiling this firmware using the official Raspberry Pi Pico SDK, system architects can toggle between these three compilation units within the root `CMakeLists.txt` file. This architecture allows the team to run empirical evaluations profiling:
1. **Instruction Cycle Latency** (Using the internal RP2040 Systick countdown registers).
2. **Mathematical Accuracy Fluctuation** (Given that the RP2040 relies on software-emulated floating-point math due to the lack of a native hardware FPU).
3. **Power Consumption Gradients** (Tracking operational current drew during heavy continuous speech processing sessions).
